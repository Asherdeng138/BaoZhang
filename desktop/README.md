# 随手报账 · 电脑版

基于手机版 HTML 界面扩展的 Windows 桌面应用，金额固定为英镑。程序内置离线英文和简体中文 OCR，不上传票据。

## 使用
1. 双击 BaoZhang-Desktop-0.2.0.exe。
2. 点击“批量添加发票”，先选择五类费用之一，再多选文件或拖入文件。
3. 工作台勾选发票，点击“识别选中”。结果为待核对状态。
4. 对照右侧原件修改日期、英镑金额、商家、所在地、分类和备注。勾选核对，保存并查看下一张。
5. 在“报账导出”中先选费用种类，再选日期和发票，生成合并 PDF + Excel。
6. 通过日历标记出差、办公、休假；颜色同时配有文字。点击日期查看发票。

## 支持范围
- Windows 10/11 64 位。无需另装 Node.js、Python 或 OCR。
- JPG、JPEG、PNG、WebP、PDF；每批最多 100 个文件，单文件最多 50 MB。
- 一个文件对应一张发票；同一 PDF 的多页放在一条记录中。
- PDF 识别前 3 页，导出所有页面。可选择具体发票导出，尚未核对的票据不参与导出。
- 相同文件内容重复导入会跳过。OCR 不覆盖已有人工填写的非空字段。
- 加密、损坏或不支持的附件可能无法识别/导出；识别失败仍可保留原件并手工填写。
- 出差餐补可按票据记录；当前没有单独的无票补贴计算规则。
- 识别不能保证准确，金额和日期必须核对；所在地需人工填写。
- 原 PDF 合并保留页面内容；数字签名在合并后的新文档中不再有效，原 PDF 仍保留。
- 每次导出最多 300 页。备份的原件和信息合计最多 250 MB。
- 左下角可备份、恢复电脑版 ZIP。恢复采用合并并跳过重复原件；安卓备份暂不支持直接导入。
- 数据在 Windows 用户的应用数据目录下，关闭/重新打开保留。移动 EXE 不影响同一 Windows 账户的数据。

## 开发与打包
Node.js 22: `npm install` → `npm run build` → `npm test` → `npm run smoke` → `npm run dist`。
`npm install` 会从官方 tessdata_fast 仓库下载离线 OCR 模型。源码和 HTML 在本目录；HTML 通过 Electron 本地接口实现文件管理与 OCR，不是独立的浏览器演示页。
