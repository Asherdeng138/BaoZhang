# 随手报账 · Android 与 Windows

中文界面的本地票据整理与报账工具：拍照或导入发票 → 离线识别 → 人工核对 → 日历管理 → 按费用种类导出合并 PDF + Excel。金额固定英镑（GBP），数据只保存在本机，无账号、无云同步，手机和电脑各自独立。

## 功能

- **五类费用**：市内交通（地铁）、市外交通、出差餐补、办公用品、客户招待。
- **离线识别**：PP-OCRv6 引擎在本机识别日期、实付金额和商家（安卓同时使用 ML Kit，Windows 失败时回退 Tesseract）。识别不确定时不自动填写，提供可点选的候选；手动修改的内容不会被重新识别覆盖。
- **自动裁剪**：识别前按票据区域自动裁剪、透视矫正和转正（两端）。安卓还可在“裁剪 / 矫正”里拖动四角微调，导出 PDF 使用裁剪后的图像；Windows 的裁剪只用于识别，导出用原图。原件始终保留不变。
- **批量导入**：安卓可多选文件逐张核对，关闭后可续接；Windows 可拖入窗口任意位置，或复制微信图片后点“粘贴微信图片”。一个文件为一张发票，多页 PDF 为一张。
- **日历**：绿色出差、红色办公、蓝色休假，可批量标记日期范围，与费用种类相互独立。
- **额度提醒**（只提示，不阻止保存或导出）：
  - 出差餐补：连续出差天数 × £50，单日可超；办公、休假或未标记日会断开，跨月/跨年不断开。
  - 市内交通：每个自然月 £150。
  - 低于额度时提示未使用金额，等于额度显示已用满，超过显示超额。
- **主界面合计**：可选统计时间（本月〔默认〕、上月、日历所选月份、今年、全部时间）和费用类别，选择在本机记住。
- **导出**：先选费用种类 → 日期范围 → 勾选发票，生成合并 PDF 和 Excel（明细 + 分类汇总，不含所在地列）。按日期排序，Excel 页码对应 PDF。文件名如 `2026-10-01至2026-10-31_出差餐补报账_发票合集.pdf`；市内交通按月份命名，如 `2026年10月_市内交通报账_明细汇总.xlsx`。只有已核对的发票能导出。
- **归档与回收站**：导出后可归档；从归档区删除才进入回收站，30 天内可恢复。
- **重复提示**：相同原件或日期、商家、金额都相同时提示疑似重复，由你决定是否保留。
- **备份**：两端都可导出 ZIP（原件 + 信息 + 日历）。Windows 可从 ZIP 合并恢复；安卓暂无一键恢复。两端备份格式不互通。

## 主要限制

- 识别结果必须人工核对；所在地手工填写。约 150 张真实票据测试中，日期、金额、商家三项全对约 61%。
- 安卓：单附件 50 MB，一张发票最多 30 个附件，单 PDF 最多 200 页，一次导出最多 200 页；合并 PDF 为图像页，不保留原 PDF 的可搜索文字和数字签名（原件仍完整保存）。
- Windows：单文件 50 MB，每批最多 100 个文件，一次导出最多 300 页，备份最多 250 MB。
- 不支持零金额、退款或多币种。

## 从源码构建（Windows）

| 目的 | 运行 | 说明 |
| --- | --- | --- |
| 首次准备安卓工具链 | `build.cmd` | 下载 JDK 17、Gradle 8.13、Android SDK 36 到 `.tools/`，需接受 SDK 许可 |
| 安卓正式版 | `tools\build-release-android.cmd` | Java 测试、lint、签名 APK、16 KB 对齐检查，输出 `output\BaoZhang-<版本>.apk` |
| 安卓测试版 | `tools\build-apk-test.cmd` | 同上，输出到 `output\test\`，不覆盖正式版 |
| Windows 正式版 | `tools\build-release-desktop.cmd` | 自动获取 Node 22，安装依赖、构建、测试（含真实 OCR 冒烟测试）、打包 EXE/ZIP，并再测打包后的程序 |
| 两端一起 | `tools\build-release-all.cmd` | 依次运行上面两个正式版脚本 |
| 发布到 GitHub | `tools\publish-release.cmd` | 需先安装 GitHub CLI 并 `gh auth login`；核对哈希后上传为最新发布版 |

日志在 `output\`。Node 测试：`node --test tests/parser.test.cjs tests/parser-sync.test.cjs`；桌面开发命令见 [desktop/README.md](desktop/README.md)。

### 签名与数据安全

- 安卓覆盖更新必须使用原签名。`.tools/personal-release.p12` 和 `.tools/signing.properties` 请私下备份，**不要提交或上传**（已在 `.gitignore` 中排除）。
- 源码备份不等于手机里的发票数据；换手机或重装前先在应用里导出备份 ZIP。
- 运行时不联网：安卓已移除联网权限，Windows 拦截所有 HTTP/HTTPS 请求。
