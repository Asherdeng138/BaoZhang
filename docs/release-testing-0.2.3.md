# Windows 0.2.3：连续拖入微信图片

已发现 0.2.3 便携 EXE 的临时解包目录复用问题：重复打开同一版本时，后启动的副本退出会清理先启动副本需要的 OCR 文件。22 张票据全失败的错误记录及隔离复现已确认这一点。请使用 0.2.5；原来的便携 EXE 只验证了启动，没有验证重复启动后的 OCR，这部分验收遗漏已在新版补齐。

旧版每次收到拖入文件时会替换待导入列表。新版把多次拖入追加到同一批次：第一张打开导入页后，可继续从微信拖入第二张、第三张，再选择费用类别并点击“导入这 N 张发票”。

- 待导入页显示数量和文件列表，支持移除单张或清空整个待导入列表。这些操作不会删除已经保存的发票。
- 一次拖多个文件和连续拖多个文件均可使用；快速连续拖入按顺序处理。已选类别保持不变。
- 每批仍最多 100 个文件，单文件最多 50 MB；超出批次数量时保留已接收的列表，提示先导入已有批次。
- 导入过程中暂不接收新批次，避免尚未完成的导入清空新收到的文件。
- 不按文件名判定重复，同名但内容不同的图片分别保留；保存时继续按原件内容校验值跳过完全相同的文件。

源码 Electron 和打包后程序均通过 `desktop/tests/multi-drop.test.cjs`：连续/快速拖入、原件逐字节保存、类别保持、移除/清空/关闭、超限保留、一次多文件、重复检查和重启持久化。另通过 11 项存储测试、浏览器界面回归、实际打包程序的单图/剪贴板回归及真实 OCR、导出、归档回收站验证。测试使用独立数据目录。

拖入测试通过程序构造 Windows 应用收到的虚拟图片事件验证，没有操作用户实际微信聊天；实际微信拖入手势仍需使用新版确认。微信没有提供可读文件时，可先复制图片再使用“粘贴微信图片”。

关闭旧电脑版后运行 `BaoZhang-Desktop-0.2.3.exe`；也可完整解压 `BaoZhang-Desktop-0.2.3.zip`，运行其中的“随手报账.exe”。包名和本机数据目录沿用旧版，Android 安装包不变。

最终便携 EXE 已通过实际解包和启动检查，版本为 0.2.3。ZIP 校验通过，打包资源与当前源码一致。本机 Microsoft Defender 4.18.26080.4-0 对新版 EXE、ZIP 与完整程序目录定向扫描均未发现威胁；未上传文件或修改防护设置。程序仍为 `NotSigned`，本机结果不能保证其他电脑的浏览器或云检测结果。安装包 SHA-256 和结果记录随交付文件提供。
