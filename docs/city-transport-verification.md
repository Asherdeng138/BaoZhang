# 市内交通月份命名与月额度

2026-10-10，用户确认：市内交通额度按自然月 £150 计算，超额只提示、不阻止保存和导出；跨月导出使用月份范围。

## 实现

- 两端市内交通 PDF/Excel 文件名按导出界面所选日期的月份命名。示例：`2026年10月_市内交通报账_发票合集.pdf`、`2026年10月_市内交通报账_明细汇总.xlsx`。
- 同年跨月写 `2026年10月至11月`，跨年写 `2026年12月至2027年1月`，不使用日。即使只勾选部分发票，月份仍由界面所选日期范围确定。
- 其他费用继续使用所选起止日期。导出筛选仍按具体日期执行；Excel 明细保留实际发票日期，分类汇总保留所选范围。
- 全月全部已确认市内交通发票累计到同一个 £150 额度，归档发票仍计入，待核对及回收站发票不计入。不同月份分别计算，不能用另一月的余额抵销本月超额。
- 日历、编辑后的确认预览、保存结果和导出页显示额度及累计金额。部分日期或部分勾选时仍核对全月总额，不按所选天数缩小上限。达到、低于、超出上限分别显示已用满、剩余额度和超出金额。
- 两端导出页预览将生成的文件名。Java 原生 Android 命名逻辑与共享 JavaScript 命名逻辑同步修改。

## 本次验证

- 解析与规则测试：`node --test tests/parser.test.cjs`，24 / 24 通过。包含单月、跨月、跨年名称、£150 的精确边界、不同月份独立额度及归档/待核对/回收站过滤。
- Windows 存储与实际文件导出测试：`node --test desktop/tests/service.test.cjs`，10 / 10 通过。核对月份文件名、Excel 日期保留、选定日期约束以及 £150.01 仍能导出。
